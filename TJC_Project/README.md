# 淘晶驰 TJC 串口屏工程搭建指南（智能学习桌面助手 · 指令集版）

- **屏幕**：TJC4827T143_011R_1_P20（4.3 寸 480×272，电阻触摸）
- **连接**：UART5（STM32 PC12-TX → 屏 RX；PD2-RX ← 屏 TX）
- **配套固件**：`bsp_tjc.c` / `app_tasks_flow.c` / `svc_timer.c`（本仓库已实现）
- **工具**：淘晶驰官网（tjc1688.com）下载 **USART HMI**
- **重要**：本屏是 **USART HMI 指令集**版本（**不支持 LUA**），所有控制代码
  直接写在**按钮的"弹起事件"**里，用指令 `printh`（发常量字节）/ `prints`（发变量）/ `dp`（跳页）。

> ⚠️ `.HMI` 主文件是二进制专有格式，必须用 USART HMI 创建布局。
> 本文档给出**全部控件清单 + 每个按钮的指令代码**，照抄即可，无需全局脚本。

┌──────────────── page_manual（手动控制）───────────────┐
│  番茄钟 HH:MM:SS（倒计时显示）                        │
│  番茄 [开始][暂停][重置]  [分钟输入]+[设时长]          │
│  风扇 [自动][关][低][中][高]                          │
│  台灯 [自动][关][弱][中][强]                          │
│  闹钟 [时][分]输入 [一次][每日][每周]  [星期]+[设星期] │

> 页面切换用 `dp=0/1`（**不能用 `page` 指令**，它会忽略后面所有代码）。

> 休眠逻辑由固件自动处理（无人→休眠→风扇/灯关闭、摄像头持续监测）。

## 一、新建工程

1. **USART HMI** → `文件 → 新建工程`，选型号 **TJC4827T143_011R_1_P20**
2. 把默认页（第 0 页）改名 **page_auto**，再新建一页（第 1 页）**page_manual**
3. 工程字符编码选 **UTF-8**（字库也选 UTF-8；若中文字库只有 GBK，工程也选 GBK）
4. **先生成字库**（TJC 无独立"字号"，字体大小 = 字库字高）：菜单 `工具 → 字库`

   | 字库名 | 字高 | 覆盖字符 | 用途 |
   |---|---|---|---|
   | ASCII16 | 16 | 英文/数字 | 番茄钟/闹钟/时长/重复/告警/按钮 |
   | 中文16 | 16 | 汉字 | 标题、中文标签/按钮 |

   **全部控件统一 16 字高**（ASCII16 / 中文16）。

5. **控件事件**：每个按钮选中 → 右侧 **事件** → 双击 **弹起** → 把下表指令**逐行**粘贴进去
   （取消勾选"发送键值"，按下事件不填）

## 四、事件配置要点

1. **弹起事件**里填上表指令，**逐行粘贴**（每行一条指令，换行分隔）
2. 取消勾选 **"发送键值"**；**按下事件**不填
3. **数字输入**：所有输入控件（npm、nah/nam、naw）勾选 **"输入"** 属性，
   点击后弹**数字键盘**直接输入（无需下拉框/状态开关）
4. **字体**：文本控件"字体"选对应字库（数字用 ASCII16，中文用 中文16）；选错则中文显示"？"
5. 固件写入的控件**名称必须与表格一致**（`tpomo`、`ttoday` 等，无下划线）
6. 页面切换用 **`dp=0`/`dp=1`** 赋值（**不要用 `page` 指令**——它会忽略其后所有代码）

## 五、编译与下载

1. `文件 → 编译`，无报错
2. USB 转 TTL：TX→屏 RX、RX→屏 TX、GND→GND、5V→屏 VCC（建议屏单独供电）
3. **先断开 STM32 的 UART5 两根线**再下载
4. `文件 → 下载`，选对 COM 口
5. 接回 STM32 UART5（PC12→屏 RX、PD2←屏 TX），复位上电

## 六、协议速查（与固件严格一致）

### 屏幕 → STM32（按钮事件帧，指令集组帧）

```
[0x55][0x0D][cmd][p1(4,LE)][p2(4,LE)][p3(4,LE)][占位2字节]
```
- 帧头/常量用 `printh`，变量用 `prints 控件.val,0`（4 字节小端）
- 末尾 2 字节为**占位**（`00 00`），屏幕不计算、STM32 **不校验**（指令集无法便捷算 CRC16-CCITT）

**帧格式示例**（固定命令一行）：`printh 55 0d <cmd> <p1 4B> <p2 4B> <p3 4B> 00 00`

### STM32 → 屏幕（字符串指令 + 3×0xFF）

```
page_auto.tpomo.txt="00:25:00"         (固件每秒推送, 文本赋值必须带 .txt)
page_manual.tpomo2.txt="00:25:00"      (手动页同步显示番茄钟)
page_auto.talarm.txt="07:30"
page_auto.trep.txt="DAILY"
page_auto.talert.txt="POSTURE!"
```

### 命令表（屏幕 → 固件）

| cmd | 功能 | 参数 |
|---|---|---|
| 0x01 | 系统模式 | p1: 0学习/1休闲/2休眠 |
| 0x02 | 外设控制 | p1: 0自动/1手动 |
| 0x03 | 风扇档位 | p1: 0关/1~7档/-1自动(0xFFFFFFFF) |
| 0x04 | 台灯亮度 | p1: 0~255/-1自动(0xFFFFFFFF) |
| 0x05 | 坐姿校准 | - |
| 0x06 | 番茄开始 | - |
| 0x07 | 番茄暂停 | - |
| 0x08 | 番茄重置 | - |
| 0x09 | 闹钟开关 | p1: 0/1 |
| 0x0A | 闹钟重置 | - |
| 0x0B | 总时长清零 | - |
| 0x0C | 闹钟设置 | p1:时 p2:分 **p3:0响一次/1每日/2每周几** |
| 0x0D | 番茄时长 | p1:分钟 |
| 0x0E | 阈值档 | p1: 0~3 |
| 0x0F | 番茄启用 | p1: 0/1 |
| 0x10 | 唤醒 | - |
| 0x11 | 校时 | p1:时 p2:分 p3:秒 |
| **0x12** | **闹钟星期** | **p1: 1=周一..7=周日** |

## 七、模式与休眠逻辑（固件已实现，屏幕只需在切页时发控制模式）

**手动控制页**（切页时发 `0x02 p1=1` 环境手动）：
1. 风扇/灯完全手动，**无人也不会自动关闭/休眠**

**自动监测页**（切页时发 `0x02 p1=0` 环境自动）：
1. 环境控制**直接按传感器自动**：温度→风扇档位、光照→白光**开关**（暗全亮/亮灭）
2. **不看摄像头/无人状态**（手动控制页切自动挡同样按传感器控制，控制权始终在用户）

> 说明：`cmd_ctrl(0x02)` 在切页按钮事件里发送，切到哪个页就切到哪种环境控制。
> 完整休眠（SYS_MODE_SLEEP）仅由手动切换触发，不再因无人自动进入。

## 八、常见编译错误排查

| 报错 | 原因/解决 |
|---|---|
| `无效指令:function ...` 等 100+ 条 | 把 LUA 代码贴进来了 → 本屏**不支持 LUA**，删掉，按本文档用指令 |
| `无效指令:-- 注释` | 指令集**不支持 `--` 注释**，事件里只写指令 |
| `变量名称无效:xxx` | 控件名不合法（**不支持下划线**，只能用字母数字短名），按本文档命名 |
| `找不到标记:数字` | 控件名解析失败的连锁错误，改好控件名即可 |
| 中文显示"？" | 字库没选中文字库，或控件字体没选 中文16 |
| 控件能收到值但显示空白 | 文本控件的**"背景填充方式"**被误改成"切图" → 改回"单色"即恢复（曾导致番茄钟 tpomo 空白） |
| 字库超内存（9MB > 3.5MB） | 只保留 中文16 + ASCII16，删掉多余字库 |
